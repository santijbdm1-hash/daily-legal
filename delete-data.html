Delete your data

Last updated: 28 October 2026

My Journal is local-only. There is no account and no server copy, so deleting the app’s data removes your journal completely. You do not need to email anyone or wait for a request to be processed.

Option 1 — Delete from inside the app

  1. Open Account from the sidebar or the floating Account button.
  2. Scroll to the Privacy section.
  3. Tap Delete all data and confirm.

This removes every entry, to-do, sleep record, review, person, event and setting from this device, then returns the app to the onboarding screen.

Option 2 — Delete the app or its storage

Android: open Settings → Apps → My Journal → Storage → Clear data. Or uninstall My Journal.
Browser copy (optional): if you ever opened a browser copy of My Journal, clear that site’s data separately in your browser settings.

Backups

Exporting a backup creates a separate JSON file on your device. The app cannot delete files you moved elsewhere, so delete those backups separately from your Downloads folder, cloud drive or wherever you stored them.

What is not deleted elsewhere

The current app keeps no server copy. If you used a version before 2.0.0, an old copy may still exist in the legacy Firebase project. Use the migration tool in the project repository (tools/migrate-from-firebase.html) to export it, import the backup, then choose Delete the old cloud copy; or contact the developer through the Play listing email to request deletion of the legacy data.

Questions? Read the privacy policy or open an issue at github.com/santijbdm1-hash/MyJournal/issues.
